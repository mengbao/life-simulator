## 简介

这是一个通过对话驱动的沉浸式人生模拟文字游戏。玩家扮演虚拟角色，经历从出生到死亡的完整人生旅程，通过选择影响六维属性发展和事件走向，最终获得个性化人生总结报告。

- **风格**：娱乐趣味型，轻松幽默，带网络梗但不低俗
- **玩法**：输入触发词 → 选择"诞生" → 在每个年龄段做出选择 → 直至人生终章
- **重玩价值**：极高，每次开局随机属性不同，选择带来完全不同的连锁反应

## 核心特性

### 六维属性系统

| 属性 | 范围 | 作用 | 自然衰减 |
|------|------|------|----------|
| 健康 | 0-100 | 寿命、疾病抵抗力、体力 | 40岁后每年-1，60岁后每年-2 |
| 智商 | 0-100 | 学习效率、职业选择、决策质量 | 无 |
| 情商 | 0-100 | 人际关系、恋爱成功率、社交事件 | 无 |
| 财富 | 0-∞ | 生活质量、可选消费、投资机会 | 根据职业和消费波动 |
| 魅力 | 0-100 | 异性缘、社交优势、特殊事件触发 | 50岁后每年-1 |
| 运气 | 0-100 | 随机事件概率、意外好坏程度 | 无（极少数事件可微调） |

### 六大人生阶段

- 👶 **婴儿期**（0-3岁）：被动接受，家庭环境决定初始属性加成
- 🧒 **童年**（4-12岁）：兴趣班、交友风格、天赋发现
- 🎭 **青少年**（13-18岁）：文理分科、初恋、高考
- 💼 **青年**（19-35岁）：职业选择、恋爱婚姻、创业投资
- 🏠 **中年**（36-60岁）：事业巅峰/瓶颈、中年危机、子女教育
- 👴 **老年**（61岁+）：退休生活、遗产规划、人生回顾

### 50+ 事件库

覆盖完整人生轨迹的随机事件系统：
- **年龄事件**：特定年龄段必定触发（如高考、中年危机）
- **属性事件**：某属性达到阈值触发（如智商>70触发天赋发现）
- **随机事件**：运气属性影响概率和结果
- **连锁事件**：前期选择触发后期专属路线（网瘾→电竞选手、天才→学术大牛）
- **稀有/传奇事件**：中彩票、车祸、百岁老人等

### 逻辑自洽系统

为确保人生轨迹不"瞎飘"，设计了严格的边界控制：

- **因果链不可断裂**：童年选舞蹈班 → 青年职业偏向艺术/网红/设计，不能直接变成程序员
- **职业准入矩阵**：医生需 iq≥80 + 顶尖学历 + 理科背景，不能从蓝领突然转行成医生
- **互斥事件组**：已婚状态永久关闭恋爱/相亲事件，文理分科后锁定教育方向
- **事件冷却期**：同类事件触发后需冷却 3-5 年，避免连续好运或连续倒霉
- **叙事回溯机制**：每次输出必须引用玩家之前的关键选择，建立连贯感
- **人设维护系统**：根据选择历史自动判断学霸型/社交型/佛系型等人设，调整叙事风格

### 多结局评价体系

**结局称号**：
- 🏆 人生赢家（财富>1000万 且 健康>60）
- 💕 情圣（恋爱次数>5 且 情商>80）
- 🎓 学霸（智商>90 且 学历≥研究生）
- 👴 长寿老人（寿命>90 且 健康>50）
- 😅 倒霉蛋（运气始终<40 且 触发3次以上失败事件）
- ✨ 传奇人生（触发5个以上稀有事件）
- 💰 孤独富翁（财富>500万 且 未婚无子女）
- ❤️ 慈善家（临终前选择捐赠财富）
- 💎 魅力人生（魅力值超过90）

**结局等级**：S / A / B / C / D

## 使用方法

1. **导入 Skill**：将 `life-simulator` 文件夹导入 SOLO 的 Skills 目录
2. **激活**：在 SOLO 对话中输入 `@life-simulator` 或直接说"模拟人生"
3. **开始游戏**：输入"诞生"来到这个世界
4. **做出选择**：每个年龄段会触发事件，选择 A/B/C/D 影响人生走向
5. **查看状态**：随时输入"状态"查看当前六维属性
6. **人生终章**：健康归零或自然寿命到期，获得完整人生报告
7. **再来一局**：输入"再来一局"重新开始全新人生

## 创作理念

这个 Skill 的核心不是"随机生成故事"，而是**构建一个有规则、有因果、有边界的人生模拟系统**。

普通 AI 讲故事的问题是：今天让你当程序员，明天突然变成宇航员，毫无逻辑。`life-simulator` 通过以下机制解决了这个问题：

1. **状态持久化**：整局游戏持续跟踪所有变量，不会遗忘
2. **准入门槛**：每个职业、每个重大事件都有前置条件
3. **因果回溯**：今天的选择会明天被引用，让玩家感受到"这是我的人生"
4. **边界控制**：属性变化有上限、事件有冷却期、互斥事件不能并存

结果就是：每一局游戏都是**独特但合理**的——既不会让你觉得被系统操控，也不会让你觉得世界崩坏。
